## 📌 Project Overview

The **Smart Bank Networking System** is a complete enterprise-level network simulation developed using **Cisco Packet Tracer**. The project demonstrates how a real banking network connects a **Head Office** with **7 Branch Offices** through secure routing and networking technologies.

The network is designed with scalability, security, and efficient communication in mind using Cisco networking concepts.

---

# 🎯 Objectives

- Design a secure enterprise banking network
- Connect Head Office with multiple branches
- Implement VLANs for network segmentation
- Configure Dynamic Routing (EIGRP)
- Apply Subnetting
- Configure DHCP and DNS
- Implement NAT
- Configure ACLs
- Demonstrate Firewall and VPN concepts
- Configure Syslog and NTP
- Enable communication between all branches
- Simulate ATM connectivity
- Demonstrate Enterprise Network Design

# 📂 Features

## VLAN

- VLAN Configuration
- Port Assignment
- Broadcast Reduction
- Department Segmentation
- Better Security

---

## Inter-VLAN Routing

Allows communication between different VLANs using Router-on-a-Stick.

---

## Subnetting

The enterprise network is divided into multiple subnets.

Benefits

- Better Performance
- Easy Management
- Reduced Broadcast
- Improved Security

---

## Dynamic Routing

Protocol Used:

EIGRP

Advantages

- Automatic Route Learning
- Fast Convergence
- Best Path Selection
- Easy Network Expansion

---

## DHCP

Automatic IP Address Allocation

Configured for all branches.

---

## DNS

Provides domain name resolution.

Example

```
www.smartbank.com
```

---

## NAT

Allows internal private IP addresses to communicate with external networks.

---

## Firewall

Provides network protection by filtering unauthorized traffic.

---

## ACL

Access Control Lists are used to allow or deny traffic based on security requirements.

---

## VPN

Provides secure communication between remote branches over public networks.

---

## Syslog

Stores logs generated by routers and switches.

---

## NTP

Synchronizes the system time across all networking devices.

---

## ATM Connectivity

ATM machines are connected securely with branch routers.

---

## CCTV

Security cameras are connected through the internal LAN.

---

## Wi-Fi

Wireless users can securely access the banking network using Access Points.
